# 日本語指示で目印を巡回する移動ロボット（MuJoCo × ローカルLLM）

Physical AI 応用1講座 最終課題の提出物です。
「日本語で指示すると、その内容を理解して目印の間を自律的に移動するロボット」を物理シミュレータ上で実現しました。

## 目的

講義で学んだ Physical AI の基本構造（認識・計画・制御の分離）を、小さくても一通り自分の手で組み上げることを目標にしました。
設計の中心に据えたのは「LLMに何を任せ、何を任せないか」です。LLMには **記号的な行動計画の生成だけ** を担当させ、実際の移動は決定論的な制御則が担います。両者の間に **検証層** を置くことで、LLMが存在しない目印や範囲外の値を出しても、ロボットには実行可能な指令しか届きません。

外部ネットワークに接続できない閉域網環境での利用を想定し、LLMはAPIではなく Colab 上で動くローカルモデル（Qwen3.5）を使っています。

## 構成

| 層 | 担当 | 実装 |
|---|---|---|
| ① 入力 | 日本語の自然文 | 例：「青い柱に行ってから、左を向いて、緑の箱まで行って」 |
| ② 計画（LLM） | 指示を行動列（JSON）に変換 | Qwen3.5-4B（4bit量子化、GPU時）／Qwen3.5-0.8B（CPU時）。思考モードは無効化 |
| ③ 検証層 | 計画の妥当性を検査 | JSONとして読めなければ再生成（最大3回）、未知の行動・目印は除去、角度は±180°・時間は0.5〜5秒に丸め |
| ④ 制御・物理 | 行動の実行と録画 | MuJoCo 上の差動二輪ロボット。`goto` は向きの比例制御＋前進、`turn` はその場旋回、`wait` は停止。追従カメラで mp4 を生成 |

行動は `goto` / `turn` / `wait` / `move` の4種類に限定しています。

```json
[{"action": "goto", "target": "blue_pillar"}, {"action": "turn", "deg": 90}, {"action": "goto", "target": "green_box"}]
```

## ファイル

- `PAI_final_rover_llm.ipynb` — 全工程（環境構築 → 走行の動作確認 → LLM接続 → 動画の結合）を1冊にまとめた Colab ノートブック
- `rover_sim.py` — ロボット定義（MJCF）、差動二輪の運動学、目印へ向かう制御、行動計画の実行、録画
- `plans/*.json` — 各指示に対する LLM の生出力・検証後の計画・走行記録（ノートブック実行時に生成）

## 実行方法

1. Google Colab で `PAI_final_rover_llm.ipynb` を開く（GPUなしでも動作。GPUがあれば LLM に Qwen3.5-4B を使用）
2. 上から順にセルを実行する。動画と計画は Google Drive の `PAI_final/` に保存される
3. 0章の最後で手書きの計画による走行動画、1章で日本語指示からの走行動画、2章で字幕付きの提出用動画ができる

描画の設定（環境変数 `MUJOCO_GL`）は mujoco を最初に import する前に行う必要があります。ノートブックではセル 0-1 がこれを担当しています。

## 工夫した点

- **責任分離**：LLMは計画のみ、移動は制御則が保証する範囲に収まるため、LLMの誤りがロボットの暴走に直結しない
- **検証層の記録**：再生成回数・除去した行動数・丸めた値の数を記録し、LLMの出力の安定性を定量的に評価できるようにした
- **ローカルLLM**：外部APIを使わず、公開モデル（Apache 2.0）だけで動作。閉域網環境でも同じ構成が成り立つ
- **目印定義の一元化**：目印の名称・位置・色を `LANDMARKS` に集約し、プロンプト・検証層・シミュレータが同じ定義を参照する

## 経緯と反省

当初は Genesis 上で四脚ロボット（Unitree Go2）の歩行方策を強化学習で獲得し、その上に LLM の計画層を載せる構成を計画していました。公式サンプルの評価スクリプトの改造まで設計しましたが、Colab 上で Genesis の起動時にランタイムのクラッシュが繰り返し発生し、締切までに学習工程を回せる見込みが立たなかったため、MuJoCo と差動二輪ロボットに切り替えました。
計画層と実行層を分離した設計のため、ロボット本体を差し替えても主張は保てています。強化学習による歩行への再挑戦、画像入力による認識層の追加、ROS 2 のノード構成での再実装を今後の課題としています。

## 使用ツール

Google Colab、MuJoCo 3.x、Qwen3.5（Hugging Face Transformers、bitsandbytes）、imageio / ffmpeg
