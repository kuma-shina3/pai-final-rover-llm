# PAI最終課題：日本語指示で目印を巡回する移動ロボット（MuJoCo × ローカルLLM）

## 構成
日本語の指示 → ローカルLLM（Qwen3.5）が行動計画（JSON）を生成 → 検証層が不正な行動・範囲外の値を除去 → 古典制御が差動二輪ロボットを駆動（MuJoCo）→ 追従カメラで録画

LLMは「どの目印へ・どれだけ回る・何秒待つ」という記号的な計画だけを担当し、移動は決定的な制御が担う責任分離により、LLMの誤りがロボットの暴走に直結しない設計としている。

## ファイル
- `PAI_final_rover_llm.ipynb` : 全工程（環境構築・走行・LLM・動画結合）のColabノートブック
- `rover_sim.py` : ロボット定義（MJCF）、差動二輪の運動学、目印へ向かう制御、録画
- `plans/*.json` : 各指示に対するLLMの生出力・検証後の計画・走行記録

## 実行方法
Google Colabで `PAI_final_rover_llm.ipynb` を開き、上から順に実行する（GPUなしでも動作。GPUがあればLLMにQwen3.5-4Bを使用）。
